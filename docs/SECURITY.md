# 安全与部署边界

1. 下载包不包含真实 API 密钥。只导入自己本地 .env。曾出现在公开 Git 历史的 key 应轮换，不要继续使用。
2. 开发登录仅在 dev/test 开放，签名身份不由 message/customer_id 字段决定。prod 禁止离线规则模型和默认密钥。
3. 管理接口必须有 ADMIN_API_KEY；它不是 LLM_API_KEY。浏览器只把管理令牌存当前 sessionStorage；避免共享设备。
4. 订单归属在 OrderService 每次校验；查询别人订单与不存在订单返回相同错误。人工审批验证类型、版本、指纹。
5. 所有售后操作是模拟。上线真实资金 API 前必须补正式授权、支付方幂等、审批审计、反重放、补偿与交易测试。
6. 数据文件包含会话/工单/检索资料，保存于 runtime，不能提交 Git；SQLite 文件权限、备份、保留期和磁盘加密由部署方管理。
7. 原生浏览器页面使用 textContent，不把模型或知识文档当 HTML 执行；同源策略和安全响应头开启。
8. 证据存在检查不是完整 Prompt Injection/内容忠实性防护。RAG 文档是低信任数据，不授权高风险动作。
9. 只开放127.0.0.1默认监听，开发客服令牌不能用于公网。正式部署先接用户 IdP、HTTPS、可信代理配置和审计。
10. 此版本按学习/迁移约定固定 LangChain 1.2.18。PyPI 于核对时列出该版本涉及文件加载/搜索 middleware 的安全公告
    (CVE-2026-55443；修复版本1.3.9)。本工程没有注册文件系统读取、搜索或不可信配置加载工具，但这不等于消除所有依赖风险。
    **公网正式部署前须重新审计依赖、升级到安全版本并跑全量回归**；不得为了保留1.2而忽略公告。
11. 默认单 API worker；跨机器会话并发和灾难恢复需在接PostgreSQL/分布式部署时专项验证，不能仅靠LLM Agent实现。
